Using Claude AI, this iphone application was created using swift.

The goal was to create an application that imports KML files that I create when I am planning my running routes.
After the KML is imported, it is brought into a map object that then shows the user where their location is based on the KML.

This was mostly done to see how xcode can work and how to use the simulated environment on my mac and on my personal iphone. This was not to teach myself how to write in Swift, just get an idea of the process of using swift to produce and publish an app. 

Apps Current state:
- Is usable on iPhone
- Can cache map area around route for use offline
- Allows the user to select KML path files on their iPhone
